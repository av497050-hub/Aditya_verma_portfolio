# Aditya Verma — Portfolio Website

A responsive, single-page portfolio for an AI & Data Science student with an entrepreneurship-focused personal brand.

## Files
- `index.html` — page structure and portfolio content
- `styles.css` — responsive visual design and animations
- `script.js` — mobile navigation, email copy button, and reveal effects
- `assets/profile-photo.jpg` — portrait extracted from the supplied resume (if extraction was available)

## Run locally
1. Extract this folder.
2. Open `index.html` in a browser, or open the folder in VS Code and use the Live Server extension.
3. Update the LinkedIn link once you provide it. Search for `LinkedIn link coming soon` in `index.html`.
4. Add your future project details in the `projects-grid` section.
